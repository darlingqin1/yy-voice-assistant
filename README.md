# YY Voice Assistant

Windows 桌面端 YY 语音助手，当前打包版本为 **0.1.5 本机验证版**。

## 功能

- 读取 YY 的真实麦克风状态，为鼠标操作和快捷键操作播放开麦/关麦提示音。
- 展示当前语音子频道成员，发言时头像亮绿圈。
- 贴边自动收起、鼠标移入展开、锁定与鼠标穿透、不透明度调整。
- 自定义显示人数上限，省略的成员说话时优先展示。
- 集中设置界面，开麦/关麦分别选择 WAV / MP3、试听和恢复默认。
- 可选随 YY 启动，配置和已导入的音频保存在程序目录。
- 设置底部检查更新；默认自动检查、下载并安装正式新版，保留个人设置与音频。

## 运行

下载程序压缩包并**完整解压**到可写目录，双击 `YY语音助手.exe`。不要在压缩包内直接运行。
需 Windows 64 位和 .NET Framework 4.8 桌面运行环境。已验证范围为开发者当前 Windows 电脑，不表示已验证所有 Windows 版本与游戏。

点击悬浮窗右上角 `···`，或右键托盘选择“设置”。双击托盘也能打开设置；退出从托盘操作。

## 当前限制

- **按实际结构判断兼容性，不限制 YY 版本号或文件指纹**。当前已验证 YY 9.59 / 9.60；内部结构仍兼容的其他构建可直接连接。
- 读取前检查实际加载的模块、对象关系、麦克风标志和列表边界；结构无法识别或数据异常时不采用该状态。未来若 YY 更改内部结构，仍需调整读取逻辑，并非保证所有版本均可用。
- 普通桌面、窗口/无边框场景可用，独占全屏不保证悬浮显示；此程序不修复 YY 自身在游戏内的快捷键问题。
- 此分发版不修改 YY 安装目录。若 YY 自身也播放开麦音，可能与助手的开麦音同时播放；原生音效抑制尚未作为分发功能实现。
- 程序未做代码签名。

## 音频与数据

默认 WAV 由 `tools/generate_sounds.py` 合成，不附带开发过程中的第三方提示音。
个人配置、用户频道/昵称诊断、测试日志和自定义音频不随源码包和程序包发布。
程序仅请求 YY 进程查询/读取权限，不注入 DLL，不写 YY 进程内存，不读取游戏进程，不录音。
源码中的预览人物为示例名称。

## 构建与打包

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
.\build.ps1 -Package
```

第一条会编译到 `dist/YY语音助手/`，第二条额外生成 `dist/YY-Voice-Assistant-v0.1.5-win-x64.zip` 和 SHA256 校验文件。
不需要安装 Visual Studio；构建脚本使用系统 .NET Framework 编译器。
`-Package` 包含运行程序、合成默认音效及此说明，不收集本机设置或日志。

可从生成目录运行不播放音频的状态逻辑自检：

```powershell
.\dist\YY语音助手\YY语音助手.exe --self-test "$PWD\dist\self-test.txt"
```

## 自动更新

设置最下方有“检查更新”按钮和“有新版本时自动下载并更新”开关。默认开启，启动 15 秒后检查，之后每 6 小时检查一次。关闭自动更新后仍可手动点击“检查更新”并安装新版。

更新源固定为本仓库的最新正式 Release，不安装草稿或预发布版本。通过 Gitee HTTPS 下载并验证 SHA256、ZIP 文件清单、程序标识和版本，校验不通过时保留当前版本。没有正式 Release 时显示暂未发布。

更新过程中助手短暂退出并重新启动；设置、原有默认 WAV、自定义音效、随 YY 启动配置都会保留。新版启动失败时尝试恢复上一个程序，保留 `.previous` 备份；结果写入程序目录的 `更新结果.txt`。程序目录需要可写、网络需要可访问 Gitee。

更新助手只替换 `YY语音助手.exe`，缺少默认 WAV 时补充。发布包中的新说明见对应 Release 或仓库 README。

维护者发布新版时，递增 `src/YYAssistant.cs` 的两个程序集版本号和 `build.ps1` 中 ZIP 版本号。创建如 `v0.1.5` 的正式 Release，附加 `YY-Voice-Assistant-v0.1.5-win-x64.zip` 及同名 `.zip.sha256` 文件，名称必须匹配。勾选预发布的版本不会自动安装。

更新逻辑自检（隔离临时目录，不退出正在运行的助手）：

```powershell
.\dist\YY语音助手\YY语音助手.exe --update-self-test "$PWD\dist\update-self-test.txt"
```
